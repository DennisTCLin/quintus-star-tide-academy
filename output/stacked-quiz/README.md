# 上下戰鬥本機驗收

本機網址：http://localhost:4348/ 。沒有部署正式站，也沒有改動正式玩家資料。

體驗帳號 `console_short`，密碼 `0742`。登入後按「繼續挑戰」。這是獨立的測試資料；可自由作答。

其他測試帳號（相同密碼）：`console_image` 題圖、`console_long` 長題、`console_englishlong` 長英文選項。原本 localhost:4197 的試演不受影響。

## 行為

- 各尺寸共用上方戰鬥、下方題目與答案；短數字答案同列。
- 長題在閱讀區內捲動；展開題目可縮小舞台，所有選項保持可見。
- 舞台高度依實際控制項與換行文字計算。手機橫放共用一列工具，答案橫排。
- 原有音訊／圖片載入作答門檻、兩小招交替、末題大招、錯題解說不變。
- 保留 main ad0b175 的勝利頁和繼續做題流程。

## 驗證

`layout-results.json`：Chromium/WebKit 共58組版面（含320×568、375×667、390×844、812×375、820×1180、1180×820、1366×768；不同瀏覽器採樣不同）。
`flow-results.json`：六題實際影片1、2、1、2、1、3，命中血量、零頁面捲動、錯答後續題。
`final-smoke-results.json`：合併最新勝利流程後的WebKit尺寸與勝利續題測試。
`tests.txt`：42項相關招式、挑戰、獎勵測試通過。`build.txt`：正式建置通過。
以上為瀏覽器模擬尺寸，未使用實體iPhone/iPad驗證。

## 重新啟動

先啟動既有本機 PostgreSQL（127.0.0.1:55432），資料庫為 `battle_cinematics_20261026`。執行 `npm run build`，再執行 `node output/stacked-quiz/start-local.mjs`。這個指令會重設上述專用測試帳號，並在4348啟動伺服器。不要對正式資料庫執行此測試程式。
