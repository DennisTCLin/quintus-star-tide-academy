# 手機與 iPad 完整流程複查（2026-10-27）

## 基線與範圍

從 main `f0fbcb5`（產品基線 `9932328`，含 PR5、PR6）開始，發布前再合併最新 main `36767aa`（PR7 小六試用校籍路由），分支 `codex/mobile-tablet-flow-audit`。此輪檢查港口首屏出發、準備畫面、六題勝利與三錯失敗、導覽觸控，以及語音收音／回覆／記憶與失敗恢復。所有資料異動僅用專用本機 PostgreSQL 隔離資料庫和合成帳號；未修改真實孩子的帳號或學習紀錄。

## 已重現與修正

三年級以上依現行產品規則不顯示一般朗讀／重播按鈕，但語音對話回覆失敗時，原先只提供「重新連線」，無法重試那則音訊。新增明確的「再聽一次」，只請求已保存回覆的音訊，不重送對話或錄音。年級朗讀政策維持原狀。

獨立複查另重現另一裝置更新對話後的 409 版本衝突：此時必須讀取最新對話，不能重試舊音訊。401／403／409 保留重新連線讀取，503 等暫時音訊錯誤則提供音訊重試。成功讀取最新記錄後清除舊錯誤提示。

## 建置與回歸

整合 PR7 後 production build 通過。一般 suite 920 項通過、181 項環境條件測試略過；另在隔離 PostgreSQL 執行 voice 與 PR7 trial suite 10 項通過。多個瀏覽器同跑時一般 suite 曾有兩個既有大迴圈超過 5 秒（readability、upper-math-server），保留首次紀錄；以 `--maxWorkers=2` 減少競爭後全套通過，未放寬 timeout 或修改產品邏輯。

## 浮動學伴整合

合併其他授權聊天的 `349e865` 來源及 `6a2c62d` 驗證。右下角改用透明 PNG，手機／平板／桌機預設角色盒 128／172／200px；根據整個按鈕矩形避開控制項，保留 8px 間距，必要時縮小到 60px 或暫時隱藏。捲動／輸入期間隱藏，停止後重算；準備、作答與對話框原有抑制規則保留。新 bow 圖為版本化新檔，舊媒體未覆寫。

來源聊天已通過 36 布局、6 互動套件和 6 WebKit 觸控案例，獨立檢查修正舊 48px 樣式造成面板角色壓扁；本聊天另檢查新 hook 生命週期，沒有證實新的阻擋問題。最終整合版再次通過 36 布局／6 互動套件（無遊戲指令或 JS 例外）。另一獨立 WebKit 檢查在 48 張卡片／52 個按鈕頁，手機與平板、32px 字體及橫直向共 169 個停捲樣本均無完整 launcher 矩形遮擋或越界；擁擠區會隱藏。

## 答題與接續

Chromium／WebKit × 一、二、四、六年級 × 接續舊局／三錯失敗／新局，共 24 條真實 UI 作答流程通過（本輪前 9 條於 main+語音修復版完成，其餘 15 條在最後整合版完成；後者含全部 WebKit 與小六案例）。每局 6 題全對到勝利，或 3 次錯誤到失敗並驗證扣血；動畫的血量需等待結算至 0，不能把中途顯示當作最終值。每條流程另驗證 4 組港口／準備尺寸、開始按鈕在首屏與無橫向溢出；最終整合導航另全分齡重測：兩引擎 × 4 年級 × 4 尺寸，共 32 組，逐一點所有主要導覽，再回港口確認首屏出發可點，全部通過且無 JS 例外。

整合版另有 8 條降服與再出發流程：三題全對加入卡片、中途關閉／重新整理保留答案、完成後返回港口可進下一挑戰。所有選項均透過 UI 點選，後端實際判分與保存；正解僅由本機 oracle 供測試選項使用，沒有新增正式答案 API。

## 語音驗證

- Chromium 與 WebKit × 一、二、四、六年級共 8 組，iPhone 13／iPad Pro 11 模擬：真實 MediaRecorder 編碼、合成聲源、兩回合記憶、音訊播放、503 重試不增加對話、AudioContext 中斷恢復、重新整理保留記憶、取消／關閉／背景停止收音、拒絕麥克風後恢復，以及 4 組橫直向尺寸；頁面未捕捉到 JavaScript 例外。
- 獨立 WebKit 複查：真實隔離後端 409、注入 401／403、503 恢復路徑通過。
- 既有 OpenAI 服務的實際 STT／對話／TTS：只使用合成海龜句子，不連資料庫；第二回合記得海龜，回覆音訊 195,456 bytes，總耗時約 11.6 秒（單次觀測）。
- 真實 Chromium `audio/mp4;codecs=opus`、WebKit `audio/mp4; codecs=mp4a.40.2` 合成錄音都經既有 OpenAI STT 正確辨識「我喜歡海龜」。
- 隔離 voice DB suite 7 項通過，含授權、CSRF、玩家隔離、版本／去重、對話保留與登出重設。

## 五分鐘 API 流量

main `f0fbcb5` 與語音修復版 `80986b9` 各在前景港口連續觀測 300 秒，兩者均為 state 109、online-battle 100、presence 30 次，共 239 次；response body 717,158 bytes、response headers 56,404 bytes。此輪未改輪詢；這是合成帳號的本機傳輸量，不代表實體裝置幀率或正式家庭資料大小。原始數據見 idle-results-voice-only.json。

完成浮動學伴整合後，以相同合成校籍／資料再量 300 秒：main 為 239 次、719,338 body bytes／56,404 header bytes；整合版為 238 次、712,876 body bytes／56,168 header bytes。差異恰為一個 state 回覆（6,462 bytes）及 headers（236 bytes），屬觀測區間輪詢邊界；不據此宣稱輪詢效能改善。見最終 idle-results.json。

所有輸出 JS/CSS 合計：main 4,767,155 bytes，整合版 4,770,909 bytes（+3,754 bytes，未壓縮，不等同首屏網路傳輸量）。新增 bow PNG 346,058 bytes，其餘媒體未改。

## 測試修正紀錄

低年級聽音題必須先播放題目才解鎖答案，測試加入實際聽題；錯題要點「看懂了，下一題」。早期小六測試把 school 直接寫進 profile，會被伺服器的帳號校籍權限清除，導致預置試卷與降服題範圍不一致；本機測試伺服器現在把合成 username 註冊到僅該程序的校籍表，對齊正式校籍路由，未放寬正式授權。反覆登入遇到速率限制時，只清理專用本機 DB 的 auth 雜湊鍵計數；未更改正式限制。

## 限制

這些是桌面瀏覽器／WebKit 裝置模擬和合成收音，不是實體 iPad 麥克風、喇叭、記憶體壓力或長時間不卡頓的證明。實機仍需按允許收音後說一短句、確認語音回覆，再問上一句內容，並做連續使用驗收。未新增第三方服務、追蹤、資料庫 schema 或經濟規則。
