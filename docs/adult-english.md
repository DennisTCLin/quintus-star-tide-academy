# 星潮 English：成人帳號、雲端進度與基礎課程

2026-11-06。繁中介面，生活／旅遊與工作英文，從基礎循序練習。入口 `/adult`，沿用既有 React/Vite、Node 與 PostgreSQL 服務。

## 學習體驗與內容

原創品牌與課程，採短課、主動回想與間隔複習，不使用 Duolingo 教材、角色或版面。成人版不套用兒童學校考試分流、神獸抽獎或戰鬥獎勵。

15 堂課、90 題，每課 6 題：

- 6 堂基礎：打招呼、be 動詞、物品、數字時間、喜好需求、簡單問句。首頁依序推薦尚未練習的基礎課，所有課程仍可自由選擇。
- 原有 6 堂情境：讓對話繼續、約時間、咖啡點餐、問路、約會議、問進度。原 36 題 `adult-en-v1-*` ID 保留。
- 3 組引導式情境對話：咖啡店、安排會議、問路到車站；每回合有角色、溝通目標、英文回應與解釋。

題型為選擇、聽句意、組句、填字、整句輸入與對話回應。正確位置依穩定 ID 分散；大小寫、空白與標點正規化，替代句採明確編寫的清單。引導對話不是自由 AI 聊天，不宣稱任意同義句或口說能力已獲認證。A1/A2 是課程編排目標，這批不是完整 CEFR 課綱。

聽力使用裝置英文合成語音，沒有外傳錄音、麥克風或發音評分。若無聲音，可展開文字繼續；伺服器先記錄提示，再顯示文字，跨裝置仍算輔助作答。

每日目標 6 或 12 個不同題目。每題每日第一次獨立答對 +10 成人學習點；首次答錯或看提示不給點，同日重做不重複計點／增加每日題數／提高複習階段。成人點數與兒童星幣、券分開。完成一組才記連續天數，不會因中斷刪除成果。

複習間隔 1、3、7、14 天。到期後獨立答對才推進；提早練習不改 due。可選到期、待修復、自由複習，每組至多 6 題。「已練習」不等於已精熟。

## 帳號與資料邊界

| 層 | 成人版 | 兒童版 |
|---|---|---|
| 入口 | `/adult` 獨立延遲載入 JS/CSS | `/`、`/admin` 入口與原 bootstrap 保留 |
| 身分 | 自行註冊成人帳號，3–32 英數／底線，12–128 字元密碼 | 原有孩子與家長帳號不改 |
| 資料 | `adult_english_users/states/sessions/receipts` | 不讀寫原 accounts、game_states、player_logins 或 sessions |
| Cookie | 獨立 HttpOnly、SameSite=Strict，正式為 Secure `__Host-star-tide-adult` | 原 cookie 不改、不作成人驗證 |
| 儲存 | 同一既有 PG，伺服器判分與更新狀態 | 原進度、獎勵、ID 與作答紀錄保留 |
| 權限 | 只能讀寫自己的成人學習紀錄 | 成人登入不取得孩子或管理後台權限 |
| 注音 | 不生成，掃描器只排除精確 `src/adult` 路徑 | 其餘既有注音審核維持 |

密碼使用既有 scrypt 與共用有限併發雜湊服務。復原碼只保存雜湊，註冊／復原後顯示一次；忘記密碼以復原碼重設時會輪替碼並撤銷所有舊成人登入，保留課程。登入後「帳號安全」可驗證目前密碼，重新產生復原碼；這可處理註冊回應遺失或先前沒存到碼的情況。沒有電子郵件寄送或管理員代讀成人密碼。

原本本機體驗版 `star-tide.adult-english.v1` 保留且可下載，不能把客戶端可改寫的 XP 自動匯入雲端。成人註冊不變更孩子帳號。所有帳號欄位的密碼／復原碼在成功登入後清除，不在 localStorage/sessionStorage 儲存。

## 同步與失敗處理

伺服器交易鎖定本人狀態，以 command ID、revision、預期 username 驗證。狀態／點數／日期不能由客戶端上傳覆寫；日期採伺服器台北時間。收據與狀態同交易提交，相同命令重送回最新狀態，不重複計點；同 ID 改 payload 被拒絕。兩裝置同 revision 只能一個成功，另一個重新同步。

登入、頁面聚焦與可見頁面每 30 秒讀取最新狀態。較舊 GET 不覆蓋新回應，也不覆蓋完成操作後的新 revision。課程與回饋持久化於伺服器，另一裝置可接續。

操作先以帳號範圍記錄待送命令至 sessionStorage，再發送；回應遺失、逾時、不完整 HTTP200 或重新整理後可重試原命令。帳號切換不會把前帳號待送操作套到新帳號。待確認時停止下一個變更，先查回結果。不支援離線連續答題；沒有確認就不顯示保存成功。備份可下載，尚無匯入功能。

## 驗證與發布

`output/adult-english/verification.json` 記錄精確候選、檢查與限制。成人內容與引擎、傳輸完整性測試獨立於兒童 content audit；真實 PG 測試涵蓋雙登入、隔離、Origin/CSRF、衝突、遺失回應重送、提示、獎勵、復原、重啟與孩子完整狀態不變。無 TEST_DATABASE_URL 的跳過不能計成通過。

僅從 canonical GitHub main 整合，與整合聊天協調單一發布窗口。發布前後對正式孩子採新的唯讀快照，核對完整 profile、revision、verified、XP、收藏、獎勵與題目歷史；有正常孩子活動時逐項歸因，禁止恢復舊快照。不得從含其他聊天未提交更動的工作樹發布。

新增成人表為可回退的附加 schema。回退程式碼時保留成人表與紀錄，不 drop/reset 任何資料；不變更服務、資料庫或原孩子 profile schema。瀏覽器視窗模擬不代表實體 iPad 的語音／長時間效能認證。
