# 星潮 English：成人版第一個可用切片

2026-11-06。目標使用者是繁中母語成人，同時需要生活／旅遊與工作英文，從基礎循序練習。

## 產品與學習設計

借用短課、每日目標、主動回想、間隔複習的學習方式，品牌與課程為原創，不使用 Duolingo 的商標、角色、教材或版面。成人首頁是一句能立刻使用的英文與一個主要開始／接續按鈕；不沿用兒童神獸抽獎、對戰、學校考試分流。

首批 6 堂、36 題（每堂 6 題）：讓對話繼續、約一個時間、點一杯咖啡、找到你的方向、把會議約好、問進度也說清楚。日常／旅遊／工作各兩課。A1/A2 是編排目標，沒有正式程度測驗或等級認證。這是有限原創入門課，還不是完整 A1–B2 課綱。

練習包括選擇、裝置合成語音聽句意、重組句子、填字與整句輸入。正確位置按穩定題號分散，不永遠在第一項。大小寫、空白與標點可正規化；替代句只採明確審核列出的答案，不用模糊比對把文法錯誤算對。每題提供中文解釋、正解與情境。

每日目標是 6 或 12 個不同題目，不以猜測的使用時間計算完成。每題每日第一個獨立正確作答 +10 成人學習點；同日再做不重複得點、提高階段或增加每日題數。點數是學習回饋，不與兒童星幣／券兌換。每天完成一組才記錄連續天數，昨日完成仍保留連續天數的等待空間；中斷不刪既有成果。

複習間隔 1、3、7、14 天。只有到期後的隔日獨立正確回想才推進階段；提早練習不加速或延後 due。答錯或用文字提示隔日再練；當日反覆答對不會把首次錯誤洗成精熟。「已練習」與完成三次到期跨日複習分開表示。可選到期、待修復、自由複習，每組最多 6 題。

## 共用框架與分開的邊界

| 層 | 成人版做法 | 原有兒童版 |
|---|---|---|
| 部署 | 同一 React/Vite SPA、同一服務，`/adult` 分流 | `/` 與 `/admin` 保留 |
| 啟動 | 成人 JS/CSS 延遲載入 | 原 bootstrap 原樣移到 `child-entry.tsx` |
| 帳號 | 本版只有一個瀏覽器內的成人暱稱，沒有建立雲端帳號 | 現有帳號與登入不改 |
| 課程 | 獨立目錄、穩定 `adult-en-v1-*` ID、情境與能力 | 保留年級、學校、出版社與冊次規則 |
| 複習 | 沿用原則，獨立小型純函式；沒有 import 兒童題庫 registry | 原 `study-review.ts` 不改 |
| 儲存 | 僅 `star-tide.adult-english.v1`，Web Locks + 完整快照衝突檢查 | 不讀寫 family/cloud/child keys |
| 權限 | 成人學習身分不等於家長或管理員 | 管理後台與孩子查閱權限不改 |
| 視覺 | 安靜海藍、文字情境、學習紀錄 | 保留兒童遊戲化體驗 |
| 注音 | 不呈現或生成注音，掃描器排除精確 `src/adult` 目錄 | 其餘所有來源仍受原注音審核 |

成人瀏覽器存檔損壞會停寫並提供原始備份，不默默清空；多分頁保存使用 Web Locks，舊分頁遇衝突必須重新載入。尚未做成人帳號切換、雲端同步、備份匯入或跨裝置使用，介面已明示限制。本版可下載備份，但不能承諾跨裝置還原。

## 後續正式成人產品的整合次序

1. **帳號與同步**：沿用現有認證服務／PostgreSQL，不另建資料庫；新增 program enrollment／成人 learner state，主鍵含 authenticated identity + program (`adult-english`)。不要把成人塞成年級 0 或兒童固定 player slot，也不呼叫 child-account provisioner。讀寫由伺服器檢查本人 enrollment；成人不因此取得孩子資料、管理員權限。以可重送 commandId + revision 設計同步，分開程式與資料遷移，先驗證既有玩家不變。
2. **課程擴充**：依能力編 A1→A2→B1 的基礎路線，再分生活、旅遊、職場支線；每課有目標句型、詞彙、對話與跨情境遷移題。加入可跳過的程度診斷，但只當推薦依據；程度不足的人從更基礎課開始，不能只換題目難度標籤。
3. **真實聽說**：補真人／授權語音、跟讀、自願錄音與可略過口說路徑。沒有實際評分服務前，不顯示發音分數；文字回答正確不代表會開口。首版裝置 TTS 不是聽力錄音認證，實際聲音依裝置而異。
4. **AI 情境對話**：以既定情境／目標句型約束，回覆需提供具體用法修正、可接受替代說法與練習下一步。服務端保存憑證及限制用量，回應失敗可回到固定課，不假造已完成評分。錄音外傳／保存方式須在真正啟用時說明。

第一版先交付可檢驗的本機切片，不變更正式資料庫或直接部署。後續從最新 canonical main 整合，不覆蓋其他發布批次。

## 驗證

詳 `output/adult-english/verification.json` 與測試日誌。16 個成人專項測試覆蓋內容、判分、重送、同日獎勵、到期間隔、提前練習、提示持久化、錯誤存檔、跨分頁衝突、台北換日與兒童入口保留。全站測試需先 build；資料庫測試沒有 TEST_DATABASE_URL 時會跳過，不能算通過。手機／平板 viewport 是瀏覽器模擬，不等於 iPad 實機或語音聲音驗收。
