## 遊戲及存檔規則

角色在既有圖鑑後追加，原有角色 ID、編號、卡片、星幣、券和獎勵不變。新角色屬於既有高階怪物分類，使用既有屬性島與稀有度抽選機制，不增加付費抽選或更動機率。

新航程和數學島關卡標記 `three-correct-v1`。獲勝時先提交原有戰鬥結算，再由伺服器建立額外三題；三題依玩家年級與科目配置，不讓客戶端指定答案或題目。降服題不另發星幣、經驗或完成獎勵。答對第三題後一次性增加一張卡，重送命令不能重複領取。答錯或明確放棄後，該場不能重試。

暫時關閉畫面、切頁或重新整理會保留降服進度。未完成時不能直接覆蓋航程；可以回到挑戰或確認放棄。原有已結算收據不重抽、不補發；升級前已開始的舊航程沿用原收據格式。存檔版本維持原值，新欄位可缺省。部署後若要回退，應使用能理解新版降服收據的修復版本，避免舊程式拒絕新產生的待完成進度。

未作答答案和未到達的降服題 ID 不送到瀏覽器。降服命令沿用現有帳號權限、CSRF、版本與冪等處理。測試使用獨立資料庫及合成玩家，不修改真實玩家資料。

## 動畫播放與無障礙

Higgsfield 生成的影片在本機完成前景遮罩處理。顏色和 alpha 遮罩放在同一個 H.264 影片的左右兩半，由 Canvas 合成；同一影片幀確保遮罩與角色同步。這避免依賴 iPad 不一致的透明影片格式，前景遮罩保護金屬鎧甲的反光細節；另外只清除已確認不在原始角色色盤中的高飽和背景色。

只在畫面可見時播放。使用靜音、行內播放；啟用減少動態效果時顯示角色圖。影片讀取失敗時保留角色圖及重新播放按鈕。離開降服題目即停止語音。實體 iPad 尚未驗證，不將 WebKit 模擬測試宣稱為實機通過。
