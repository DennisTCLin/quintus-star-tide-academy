# Feifei 二年級戰鬥畫面修正

以正式版 8821aab（文件提交 0707bad）為基底，只調整 App 聲調答案容器標記與 quiz-console.css。未變更玩家年級、題庫、伺服器、判分、獎勵或存檔。

## 根因與修正

1024×650 WebKit 可重現：四聲答案沿用圖片選項，兩排共佔約 308px，戰鬥區只剩 103px。角色頂端 91px，血條區底端 120.5px，存在約 29px 遮擋。

聲調選項使用 48px 符號與文字，700px 以上改為一排；角色高度上限預留血條／名稱區。修正後同尺寸戰鬥區 195px、角色約 125px，頂端 121.7px，完整位於血條下方。短螢幕或主動展開題目仍優先保留閱讀、答案與下一題空間，角色會縮小。

## 題目年級核對

- `server/school-roster.mjs` 的 feifei 與 `src/game-view.ts` 的 feifei 都設定 grade 2。
- `startRun` 依 PLAYERS 的年級選題；二年級聲調題 ID 使用 g2，選項為四聲。一年級同一個舊版純聽音題型比較二聲、三聲；另有較新的句子聲調題，不能只憑選項數判斷全部一年級內容。
- 與 1e39713 比對，二年級一般題庫、課程目錄與帳號設定沒有因本次數學島整合被改成一年級。
- 照片題型符合既有二年級聲調基礎練習，但該題庫本來偏基礎，不代表完整二年級國語教材。未擅自更改孩子的進度或移除她已選的航程；也沒有宣稱已完成學校課次對齊。
- 核對範圍為版本程式、帳號設定與合成出題；未登入孩子帳號或讀取她的正式作答存檔。
