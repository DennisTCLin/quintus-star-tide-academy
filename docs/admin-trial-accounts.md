# 超級管理員建立試用帳號

入口：管理艙 → 試用帳號。只有 super_admin 可查看清單、建立與核對結果；一般管理員即使有發券權限也無法使用。

提供一、二、四、五、六年級，三年級標示尚未開放。稱呼與登入帳號可自訂，密碼為四位數字；預設 5,000 星幣、20 星願券、5 星耀特邀券，可在上限內調整。帳號與進度獨立，不建立其他玩家的好友關係。

「預備初始夥伴與新怪物戰鬥」預設勾選：正常挑選初始夥伴，準備至練習階段 5，分配一場尚未作答的新怪物數學挑戰。學科作答、通關與降服由試用者實際完成。取消勾選則保留首次選夥伴流程。

每個年級採用現有且可實際分配五科題目的教材方案，不作為校籍聲明。伺服器以 player_logins.trial_curriculum 及已登入的年級槽位解析；無法從客戶端指定或冒用其他玩家的教材。先前建立的 trial_g6 仍可登入，並顯示在試用清單。

## 一致性與憑證

新增 nullable trial_curriculum 欄位與 admin_trial_accounts 建立紀錄表。帳號、雜湊密碼、初始額度、教材、未作答航程與 audit 在同一交易提交。相同 requestId 重送只回傳原結果；重複登入名稱不覆寫舊帳號。寫入時重新鎖定並驗證超級管理員權限與登入。

requestId 和非秘密設定可暫存在管理員自己的 sessionStorage，以便斷線／重新整理後核對；密碼只在表單與第一次完成畫面的記憶體中，不存入 sessionStorage、建立收據或 audit，清單與核對 API 也不傳回密碼。建立完成可複製登入資訊。失去回覆後可核對結果；若尚未找到，可用原編號和原密碼重試。

## 驗證

- 正式 build PASS；929 一般測試 PASS（已整合手機／iPad 及題庫主版 1157430），192 需 DB 案例在一般執行時略過。
- 10 項新隔離 PostgreSQL 案例 PASS：權限與 CSRF、五個年級各兩種準備模式、正確題目分配、唯一性、重送／並行、額度界線、原帳號保留、audit 失敗整體回滾、寫入前權限重驗、無憑證洩漏。
- 既有超管、權限與獨立玩家帳號三套 DB 回歸，共 39 項 PASS。
- Chromium／WebKit 實際 API 後台操作 8 項 PASS，393／768／1024px 無橫向溢出。包含實際建立後以新玩家登入、重複帳號可改正、提交成功但回覆遺失後重新整理核對，以及 staff 不顯示入口。
- 保留全部既有注音內容，只新增後台需要的 56 個詞組並重建壓縮字典。實體 iPad 尚未測試本次後台。

## 發布與復原

本功能的 schema 只新增欄位與表，不刪除或重設任何玩家資料。發布要接上當下最新 main，保留手機／iPad 與全部媒體更新。若需回復功能，保留新試用帳號的教材解析，採向前修正；不要因關閉後台入口而清除試用帳號、額度或進度。
