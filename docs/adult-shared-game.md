# 成人與孩子一起玩星潮學院

入口 `/adult` 沿用兒童版實際的 `Game`：同一套港口、動態群島、初始夥伴、收藏、扭蛋、領地、好友、線上對戰與共同征服。成人的學習入口改成英文島，題目仍使用既有成人課程與穩定 ID；兒童學校、年級、出版社與題目分流不改。退休的獨立成人儀表板不再作為入口。

## 原身分與成果保留

`adult_english_users.id` 是原成人身分的唯一依據。`adult_game_enrollments` 將這個 UUID 原樣連到相同 UUID 的遊戲帳號和玩家，沒有依同名帳號合併、改密碼、重建或搬移孩子。既有六個 profile slot 只作內部儲存結構；成人公開 metadata 是 adult-english、grade null，不能藉 slot 推論為四年級學生。管理後台學生名單、學校報告與兒童權限範圍，依正式 enrollment 排除成人。

成人原有課程、複習、作答、復原碼、登入方式和 XP 完整保留。第一次開啟遊戲時，既有伺服器核定英文 XP 只折算一次星幣和熟練點，不虛構過往夥伴 XP 或航程。成人遊戲使用原成人 HttpOnly cookie，與孩子 cookie 並存，命名空間分開。登出或復原會撤銷相應相容 session，不能留下可繼續遊戲的舊登入。

新英文作答與遊戲獎勵在同一資料庫交易提交：每題每日第一次獨立答對得 10 英文 XP、10 星幣、20 熟練點、至多 10 夥伴 XP，並推進共用建材機制。提示、當日重做或收據重送不重複領獎。新領取至少四題獨立答對成果的六題課程，完成後每天每課最多一顆星願；兩顆換一般扭蛋券。三錯結束，已取得成果保留。複習可以重新取得跨日獨立作答獎勵，但不發六題課程完成星願。

夥伴與戰鬥能力在開課時固定；中途換裝不會把同一場 XP 改給另一隻。戰鬥、題目與回饋可重載和跨裝置接續。日界線由伺服器台北時間判定；不接受客戶端上傳日期、點數或遊戲快照。成人不使用兒童題目或兒童的降服加試題。

## 家人同玩

依使用者選擇，家人分享 24 小時、單次使用的邀請碼。對方送出申請後，邀請人必須確認，才建立雙向好友。可拒絕；未連結成人不能查陌生孩子收藏或邀戰。成人自行註冊不會自動加入孩子好友；只有既有兒童或已確認家人的成人，才能開通另一成人的共同征服存取，兩個未確認的成人互加不會自行開通全站戰場。

線上對戰使用雙方真實玩家 UUID、目前收藏和各自的夥伴能力。成人和孩子即使內部 slot 相同仍是兩位不同參與者。沿用原有邀請、接受、回合與勝負規則；助戰題成人只出成人英文，孩子仍使用自己的課程。共同征服使用同一世界與分別的參戰身分、收藏、能量。

## 跨帳號交換

好友交換是獨立的伺服器交易，不把原本同家庭交換冒充跨帳號功能。雙方各選一張不同的非初始卡片；提出邀請時不扣卡，接受時再鎖定兩份存檔，檢查好友、收藏、進行中的學習與待完成交換。只有收件人能同意或拒絕，寄件人可取消。接受、拒絕、取消與重送均有耐久收據；接受與取消競態只能提交一個結果。

交換只移動各一張卡。最後一張送出而原本裝備它時，回到自己的初始夥伴；自己的卡片經驗與等級繼續保留，不能把他人的學習 XP 當作卡片一起轉走。幣、券、星願、熟練點、題目歷史、學校設定與其他孩子的 profile 不受交換影響。雙方有進行中學習時要先結束，避免任務中的夥伴突然消失。未確認回應時只能重試原交換操作，不能連續建立新交換。

同家庭原有交換仍保留。這批不提供自由聊天、陌生人搜尋、全站成人加好友、跨帳號贈送貨幣或管理員權限。

## 驗證與回退

驗證紀錄位於 `output/adult-shared-game/`。使用合成成人與兒童帳號做真實 PostgreSQL、完整對戰、交換競態、重送、登入恢復、服務重啟與完整資料保留檢查。手機/iPad 尺寸的瀏覽器 QA 不是實體 iPad 或 WebKit 認證；未實測的項目明確列出。

只經 canonical GitHub 流程整合。發布前由整合窗口協調新的唯讀正式資料 before/after 保全；測試只寫入合成 QA。回退保留所有附加表、遊戲成果及收據，不 drop、不重設、不恢復舊快照。
