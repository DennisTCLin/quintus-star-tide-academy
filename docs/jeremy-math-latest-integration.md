## Jeremy 移入的功能

- 全年級依學期與單元順序呈現，二至六年級新增 92 單元、309 玩法。
- 每個單元有「學一學、玩一玩、挑戰神獸」，各年級有獨立全學年複習、神獸完成紀錄與島主綜合挑戰。
- 分步動畫與語音教學，支援暫停、重播、切換步驟及離開時停止播放；包括分數、角度、面積、圓面積、體積等示範。
- 一年級支援 0～100 數字鍵盤；高年級使用數值、分數及單位答案卡。
- 明確顯示年級、學期、單元、階段與本關題數；熟練度另外呈現，可查看小本領，以最近三次首次作答計算，訂正不重複計入。
- 可確認後換島，保留已獲得的獎勵與紀錄；重新整理可以續玩。
- 右側直排注音、必要數學詞組及手機版面修正。680px 以下進度區隨內容捲動，避免遮住數字鍵盤。

## 保留目前功能與衝突處理

唯一文字衝突是 `src/App.tsx` 的科目選單。採用目前版本的 `selectIsland` 與常駐五科選項，只把數學島入口擴充到全年級，沒有採用舊整合稿直接跳頁或直接開新題的處理。合併後與維護基底相比，App 僅五行換入、五行換出。

因此待補練時仍可選其他科目；同科續玩、取消換科不寫入、未領獎勵先領取、結束原航程後換科等原有流程都保留。另實測數學島與普通科目雙向切換，確認不會跳過這些流程。

- iPad 下一題的可用高度計算與 CSS 完整保留；即使好友對戰通知仍在，下一題仍可點擊。
- 首頁動畫群島、個人學伴與動畫素材、收藏、扭蛋、好友、對戰、領地及帳號維持目前實作。`public/` 沒有變更。
- `src/cloud.ts`、學校名冊、server 入口、套件及 Vite 設定均與維護版相同；來源預覽版的 `src/browser-id.ts`、`src/presence.ts` 未移入，維持原本不存在的狀態。
- 既有存檔版本仍為 **9**；Alston/Jay 遷移與舊數學島 ID 仍可讀，未清空玩家存檔。保留現行捕獲率驗證及歷史收據相容性。
- 沿用伺服器判分、保存、獎勵、未作答答案遮蔽及重複請求防護。只有已知數學島 ID 可進入擴充的獎勵帳本；普通科目的年級及題目驗證不放寬。
- 注音字典所有原校對值保留，僅新增 38 個數學詞組，再重建一般與壓縮字典。
- 一併保留我們先前的 Jay 五年級數學額外 20 題提交 `8db09b6`，本分支五年級共 160 題。這不是 Jeremy 新增的內容，也尚未部署。

排除 Jeremy 的匿名試玩、試玩資料庫、帳密、Cloudflare 分享、私人網路 UUID 相容性、全域代理及 dist/build 產物。新驗證資料夾只有測試腳本、結果與合成畫面，未包含資料庫或真實玩家存檔。

## 限制與後續驗收

- 尚未在孩子的實體 iPad / iPhone 上驗證動畫效能與系統語音聽感。Chromium / WebKit 觸控模擬不能宣稱等同實機驗收。
- 建置仍有大型區塊提示；本次未量測低階裝置下載、記憶體與動畫效能。
- Jeremy 課程依翰林編排；不代表已對齊 Jay 的南一版本或每位孩子 115 學年度評量範圍。
- Jasper 的普通科目新題不足與提示出現在畫面外是另案已確認問題；本次全年級數學島整合沒有補足其英文、聲調、拼音或辨音題池，也沒有宣稱修好該提示位置。見 [Jasper 檢查](jasper-subject-check.md)。
- 本次沒有新一輪 Council／獨立人員審查；舊整合稿的歷史審查紀錄不等於本次多人評審。
- 所有變更僅交付分支，main 與正式站維持原狀。若日後上線且產生新進度，不可回退到只接受一年級數學島的舊驗證器；應保留新欄位及島題 ID 讀取能力，必要時先關閉新入口。
