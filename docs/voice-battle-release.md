# Kiki、即時學伴與戰後補練整合

## 行為

- 七段固定語音使用已選定的 Kiki：歡迎、麥克風教學、摸摸、餵食、玩耍、鼓勵、休息。來源與 SHA-256 記錄見 `outputs/tideglow-voice/kiki-provenance.json`。
- 即時聊天依使用者選擇暫用 OpenAI 聲線。可錄音、接續前文、重播及打字；每個孩子的最近 12 輪對話分開保存，最多 7 天，可清除。原始錄音不寫入資料庫。
- 取消、關閉或切至背景停止收音；延遲的圖卡回覆及補練換題不會取消之後才開始的麥克風。錄音採瀏覽器支援格式，Safari 的 AAC/MP4 亦已驗證。
- 新版開始的戰鬥失敗後，可訂正所有實際答錯或超時的題目。全數完成後，將本場星幣與 XP 合計補到六題全對的一半，通常最多各 30；原先已得的計入，不額外再加半份。沒有額外星願券、建材或夥伴。
- 原始作答與戰敗紀錄保留。部分訂正、錯誤訂正、跨日、練習及舊版未保存補練額度的戰鬥，不另外補發獎勵。略過補練會留下結算紀錄。
- 獎勵與收據在同一資料庫鎖定交易寫入；命令重送、不同命令 ID 並發、重新整理及跨裝置不能重領。換島會提示待補練事項；返回可正確接回補練。
- 補練保留原題錄音、圖片圖集、注音和適用英文題的逐選項發音。答對戰鬥題後自動進入下一題，可暫停；離線、背景或離開畫面不自動送出。

## 驗證方式與限制

整合使用隔離的本機 PostgreSQL 測試資料庫與合成帳號，沒有操作正式孩子的遊戲存檔。端到端語音使用合成 MediaStream 與真正 MediaRecorder；UI 服務的 AI 回覆是固定測試資料，不能當成真實 AI 品質證據。另一次真實 OpenAI 合成音訊／兩輪對話測試見既有 `outputs/tideglow-voice/live-provider.json` 和 `verification.json`。

本輪涵蓋完整自動測試、21 項元件互動、WebKit iPad 觸控錄音、取消釋放、重播、拒絕權限後恢復、聊天持久化與孩子隔離、320/390/768/1024 寬度及完整戰後補練結算／重新整理。

WebKit 在重新載入頁面時，會將已由應用程式捕捉的 `/api/state` fetch 取消顯示為 access-control 診斷。獨立重現顯示只在 reload 發生，重新登入選角後狀態正常；測試保留該診斷，不將其誤記為完全無瀏覽器警告。

本輪移除了新聊天程式對 `Array.prototype.at` 的依賴。WebKit 模擬及 macOS Safari 測試不等於實體 iPad 驗收；另一對話回報的第七代 iPad，已確認使用 iPadOS 18.7.10，但仍待實機載入診斷，沒有據此斷言硬體故障或根因。

實際測試與發布結果另記於 `outputs/voice-battle-release/release-verification.json`；發布後以 HTTP 狀態及 JS、CSS、七段 Kiki 和原有潮光獸動畫的雜湊核對正式站。
