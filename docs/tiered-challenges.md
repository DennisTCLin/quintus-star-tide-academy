## 實作決策

- 新航程凍結獨立的 version 1 challenge 合約；戰鬥能力 V1/V2 與既有無此欄位的航程完全沿用。不是變更舊 combat 公式。
- 野外怪物實際等級 1–9 / 10–19 / 20+ 對應初階／進階／高手。每場六題，分別需答對4／5／6題。第三次錯誤立即結束；未達勝利門檻但尚未三錯，仍可完成其餘題目並保留答題星幣。
- 題庫只在該年級內選難度1／2／3；對沒有三個難度的科目選最近的現有難度，明示實際題目難度，不捏造難度、不跨年級。保留有限題庫的不重複游標與標示複習。
- 標準限時：一年級90／85／80秒，二年級75／70／65秒，四年級60／55／50秒。這些是保守首版參數，不宣稱經過兒童實證。
- 每題先呈現準備畫面；按開始才由伺服器揭題並保存 deadline。另按題目長度保留30–120秒讀題／聽題期，可提前作答；倒數與作答期分開標示。媒體故障有文字／求助及下趟慢慢想選項，不宣稱所有音訊必能在緩衝內完成。
- 伺服器收到答案時間 <= deadline+2秒才接受；超時記一次錯誤，沒有該題獎勵。刷新／切背景不重置，不提供無限制可作弊暫停。斷線重連照已保存期限判定；已領星幣保留。
- 開始前可選慢慢想（不計時），相同題庫、答對數與獎勵。模式整場固定；不設速度排行榜，因此無須把閱讀障礙當成懲罰。標準模式仍有實際限時。
- 新捕獲與連續獎勵規則保持：成功就有固定機率邀請一次、每兩次成功給券；失敗不發完成獎勵。
