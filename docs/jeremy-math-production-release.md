- 發佈前逐檔核對 1,805 個 dist 檔案；其中 1,793 個既有公開素材由前一版正式站還原，建置時檢查每檔長度與 SHA256，全部通過。

- 正式站 21 個檔案雜湊符合本機已驗證版本，包含入口、全部此次產生的 JS/CSS 及斐斐、庭羽、潮光獸的擊掌／吹泡泡／休息影片。
- 未登入 `/api/state` 仍回傳 401，沒有取消登入保護。
- Chromium 與 WebKit 共 14 組正式素材檢查通過：393px／834px 五科入口、六個數學年級及三階段、無橫向溢出、斐斐與庭羽專屬學伴及休息圖片、好友通知出現時下一題可點擊。

- 沒有還原、清空或重設正式資料庫。
