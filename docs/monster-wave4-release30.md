## 驗證

正式建置 PASS；882 單元測試 PASS，179 需資料庫案例在一般套件執行時略過；另外以 23 個獨立測試資料庫執行 182 項 PASS。降服成功／失敗／重新整理續接 16 個實際 UI 流程 PASS。原始素材 300 項雙引擎播放驗證既有紀錄仍有效；發布備援動作另跑 60 項雙引擎驗證。桌面 WebKit 不能代替實體 iPad，實機未驗證。

## 發布與復原

部署包只包含 30 隻的 60 張 WebP 和 120 支安全影片，既有 public 素材逐一與基底核對 SHA256，部署建置再由現有站還原並核對。發布後核對資產、登入頁與 API 權限。

在任何玩家取得新卡或產生 version 3 降服狀態後，不能直接退回舊版伺服器，因為舊版不認得新資料。需要修復時保留這次的資料解析與怪物 ID，採向前修正或關閉新遭遇入口，不刪除既有卡片或進度。

正式發布結果另記於 outputs/monster-wave4/production-release.json。
