# 潮光獸陪伴動作：2026-10-25

這批把港口的三個 emoji 按鈕擴充為六張與學院標誌一致的圖像按鈕。以不識字的一年級孩子能獨立開始、知道下一步、隨時結束為目標；二年級仍顯示中文與注音。

## 動作與回應

| 動作 | 孩子的操作 | 潮光獸的回應 |
| --- | --- | --- |
| 摸摸 | 點頭部或橫向輕滑；也能按圖卡 | 原有摸摸影片、星光與 Kiki 回應 |
| 餵點心 | 點圖卡；或把點心拖到角色區 | 原有餵食影片、點心語音 |
| 星光球 | 依序點三顆球 | 逐顆點亮進度，完成後歡呼 |
| 擊掌 | 點亮起的手掌 | 歡呼動作、完成星星與擊掌語音 |
| 吹泡泡 | 任意順序點三個泡泡 | 泡泡變成星星，全部完成後歡呼 |
| 一起休息 | 隨時點月亮圖卡 | 立即取消遊戲與鎖定，切換休息動作與語音 |

使用現有 TideglowActor 影片狀態與有限次 CSS 星光效果，沒有新增影片。沒有倒數、扣點、獎勵或帳號資料變更；互動進度是本次面板的短暫狀態。舊摸摸、餵食、星光球的引導脈絡更新仍保留。新動作不送到舊的 guide API。

切換聊天、收起面板或分頁進入背景時清掉本次動作及語音。延遲抵達的圖卡引導不會自動朗讀、打斷之後的收音。重複點擊不能多算進度；取消觸控手勢不會吞掉下一次鍵盤操作。減少動態／暫停動態時使用靜態角色，遊戲仍可完成。

## 媒體與注音

- Higgsfield `gpt_image_2_5` 依學院小龍參考圖生成 3×2 圖集，交付為單一共用 WebP（768×512，61,096 bytes）。主色是深海藍、薄荷青、星光金。載入失敗有圖形備援。
- 六支新增固定語句使用已選定的 Higgsfield Kiki，合計 224,142 bytes，沿用既有固定語音播放與取消機制。自由對話仍用既有 OpenAI 語音服務。
- 來源、工作編號、SHA-256 與時長分別保存在 `outputs/tideglow-care/art-generation.json`、`voice-generation.json`。
- 新增台灣詞語覆寫並重建介面注音：[擊掌](https://dict.concised.moe.edu.tw/dictView.jsp?ID=21517&la=0&powerMode=0)（ㄐㄧˊ ㄓㄤˇ）、[泡泡](https://dict.concised.moe.edu.tw/dictView.jsp?ID=2712&la=0&powerMode=0)（ㄆㄠˋ ㄆㄠˋ）、[搭檔](https://dict.concised.moe.edu.tw/dictView.jsp?ID=6717&la=0&powerMode=0)（ㄉㄚ ㄉㄤˇ）。
