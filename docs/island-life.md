# 夥伴的小日子

領地的「城堡內部」建築地圖會顯示目前玩家擁有的夥伴。包含原有角色、花園夥伴、降服怪物與新圖鑑；同種多張卡只出現一位。桌機最多 8 位、手機最多 6 位，45 秒輪替，保留目前陪練夥伴，也可以手動換批。

夥伴沿草地／步道散步、休息、睡覺、玩球，附近的夥伴可一起玩。點地圖上的夥伴或下方頭像可打招呼。頭像列保留名稱、稀有度與目前等級。這些是純視覺互動，不消耗資源或發送遊戲 command。

安全地面多邊形與有建築土地的橢圓底座共同產生導航網格。移動只沿通過檢查的相鄰節點；中途被招呼或同伴邀玩後繼續原路，避免穿建築。以落地位置決定遮擋順序，經過土地操作區時讓出指標點擊。

單一 RAF 每秒最多更新約 30 次 DOM transform，不逐幀重繪 React。暫停、搬移建築、系統／家長艙減少動畫、切到其他分頁或地圖捲出畫面時均停止；卸載時清除 RAF、observer 與監聽器。大量收藏輪替顯示，不同時載入全部 135 張角色圖。有明確 thumbnail 的角色使用縮圖。

驗證：`npm run build`；`TEST_DATABASE_URL=… npm test -- --maxWorkers=1 --no-file-parallelism`；`scripts/verify-island-life.py`、`scripts/verify-island-life-extra.py` 使用隔離 API fixtures 進行 Chromium 瀏覽器驗證。`outputs/island-life` 保存行為、效能與獨立複查結果。瀏覽器視窗包含 320、390、768、1440px；不宣稱已於實體手機測試。
