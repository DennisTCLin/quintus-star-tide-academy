# 題庫內容檢查員

目的：孩子取得完整、可解且有可追溯審查的題目。檢查在建置時執行，不在孩子作答時呼叫 AI。

- `npm run audit:content`：核對所有固定題、全部有限生成題、媒體、來源及審查證據。任何缺漏、未核准、隔離或雜湊不符均非零退出；`npm run build` 必須先通過。
- `npm run audit:content:inventory -- --export /tmp/content-review`：產生盤點、逐題雜湊及每包 60 題的盲審輸入。此命令不產生核准，不可替代發布檢查。
- 盲審輸入不含標準答案、提示或解析。請 AI 先解題，之後比對答案與解析、圖片／音訊依賴、年級及出版社／冊次；有疑義先標 pending 或 quarantined，留下原因。
- 固定題逐題記錄；生成題按模板審查並跑完整有限參數空間的程式驗算。每次變更生成器都使模板核准失效。
- 只有審查完成後，由維護者將 `approvals.json` 的對應狀態、雜湊、reviewer、evidence 更新並提交。不得把 inventory 結果自動視為 approved；無自動核准旗標。
- 修正題目保留語意對應的既有 ID 與作答紀錄，不清除精熟度或獎勵。要改考點／正解時另建版本 ID，並保留歷史題目解析能力。
- 閘門阻止含問題題目的新版本發布；不會自動修改正式資料庫或遠端停用已發布內容。遇正式問題需修正後發布，或另行實作經授權的停用機制。

報告 `output/content-audit/report.json` 分列固定題逐題 AI 文字審查、模板 AI 審查、全部變化機械驗算。音訊試聽與每張圖片的語意驗證另計，不宣稱已完成。

未實作新複習模式、作答流程、獎勵變更或管理員後台頁面；這次提供可重跑的命令與可稽核紀錄。
