# 學習體驗與複習模式（2026-10-26 已授權實作）

目標：讓孩子接著練，也能隔一段時間再次回想。保留永久精熟、點數、夥伴、原挑戰與原補練權益；不清除進度來製造新題。

1. **再練一組**：挑戰結束可以再練、複習錯題或換科目。獨立複習每組最多六題，數量不足時如實顯示；原挑戰仍維持六題及既有領獎條件。新題不足時提供直接開始複習的入口。
2. **錯題修復**：答錯先看完整題目、正確答案與解說，手動繼續。獨立複習把原題排在至少兩次實際作答之後；不足以間隔時留到之後／隔日，標示原題重試。一般挑戰的戰後補練與半額補償保持原規則。
3. **今日複習**：以伺服器臺北日期保存每題紀錄，初始跨日間隔為 1／3／7 天（`REVIEW_INTERVALS` 集中設定）。同日反覆答對不晉級；答錯或使用提示會回到隔日複習。保留舊精熟，但沒有日期的舊題不虛構逾期。每組可暫停、換裝置接續或結束重選；學校版本變動後仍能結束舊組。獨立複習完全不發新獎勵。
4. **家長摘要**：孩子家長艙與超管選定孩子的唯讀家長艙，呈現未提示正確率、獨立作答分子／分母、到期題、跨日再次答對與經常需要提示的能力。不擴大既有管理員權限。

統計每題每日第一次作答；重試不灌高正確率。紀錄從功能啟用後開始，未補造過去日期。弱項需至少三次作答（含提示）才列入；沒有紀錄時顯示尚無資料。**一年級數學島是獨立引擎，保留原有示範／闖關及摘要，不納入這次題庫複習的新統計。**

題目沿用年級、課程、學校、出版社與英文冊次規則。低年級保留必要錄音、圖像、注音與英文選項聆聽；三年級以上不新增朗讀按鈕。複習沿用既有雲端交易、版本衝突與重送收據，伺服器決定題目、日期及答案，不接受客戶端自訂分數或獎勵。

驗證包含：舊資料／備份合併、獎勵欄位不變、重送與競態、跨裝置接續、錯題間隔、跨日排程、學校篩選、少量題庫、全題耗盡、手機捲動、音檔完成解鎖與管理員所選孩子隔離。證據在 `output/study-review/`。

回復版本時應保留 `learning.study`，不要為回復介面而清除既有資料。這次沒有資料庫結構遷移；新欄位為選填，舊存檔不需要重設。

初始間隔是產品設定，不宣稱為每位孩子的最佳間隔。原提案依據：IES [Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。
