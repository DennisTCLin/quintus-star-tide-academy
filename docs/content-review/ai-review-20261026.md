## 發現與修正

- 數學長度及角度解析改為逐項指名，移除選項旋轉後失效的「依序」。
- 三道容量題補足裝滿、倒盡、同樣大小小杯、沒有剩餘的條件。
- 航海圖分數加法補足塗色不重疊條件。
- 「一般／投進／依依不捨／淙淙」補足語境，使答案唯一；「炒」限定少量油翻動菜餚。
- 「鬧」的外部更正為「鬥」，不是「門」。依教育部國語小字典的鬥部字形（https://dict.mini.moe.edu.tw/SearchIndex/word_detail?dictSearchField=%E9%AC%A7&wordID=D0002277）。保留既有題目 ID；匯入腳本保留原始 ID 鍵。
- 英文補足下雪、不開心、非難過、難過哭泣等明確情境，避免從活動／情緒推論不成立的相反狀態；新增條件明標「情境」。
- Grandma 題改問「短文明確陳述」是否為真，避免把未交代的狀態視為假。
- 英文改寫模板正確處理 shell／shells；原先 60 個題目實例含單數一致性問題。
- 一年級兩個注音符號的題目改問ㄧ／ㄨ／ㄩ，不再稱「中間」；二年級乘法提示改為累加。
- 賞荷季節補上臺灣地理條件。

## 審查邊界

文字與字音資料已讀；錄音未逐一試聽、圖片裁切未逐一視覺檢查、未重新將全部歷史題與原 PDF 比對。本次媒體檢查是存在性及內容雜湊，不是聲音／圖片語意認證。AI 仍可能漏判；本報告不代表零錯誤保證或 115 學年度實際考試範圍已確認。
