# round6紙本語境讀音修訂

本修訂取代6d2a4919及原181項證據對最終讀音語意的放行結論；原181檔與索引保持歷史原樣。35題題幹、選項、答案、數量、來源族、既有6729題物件與23192產生題不變。

完整盤點原字典78個含卷全文鍵，具名固定89個明確試卷／書籍語境的全文讀音，並精確修試卷、書卷與手不釋卷。相對c66是43個既有全文詞組僅卷三聲改四聲、210個新增詞組與19字；沒有全域修改卷或捲字fallback。除字典既存詞組，另從真實static／generated／metadata擷取14個動態組成的完整中文詞段，避免只掃字典而漏原卷註／原卷文字題改編等。原卷／整卷不加成裸詞規則，避免還原卷曲、整卷紙等別義跨詞。銀絲卷、捲曲保留三聲；字形題故意錯拼的勝卷在握／禮卷不概括認證詞義讀音。指定舊國語題的真實四選項與完整explanation已直接回歸：手不釋卷／考卷／試卷四聲，銀絲卷三聲。

真syllables全量檢查6729個舊static物件、23192個generated與268個舊來源metadata，逐ID／欄位記錄完整前後讀音；目前791欄影響（static697、generated0、source94），包含原空音補齊及精確紙本語境修正，不能再稱所有舊讀音不變。題目物件、答鍵、帳號／進度／獎勵機制不改。詳細分類、原始測試、獨立覆核及最終head/index以verification/evidence為準。
