# 全站注音與朗讀修正驗證（2026-10-25）

## 範圍與依據

覆蓋所有維護中的 src TypeScript/TSX、題目生成器、角色／技能、領地、介面，以及 165 個花園課程詞項。掃描 2,843 個原始碼中文字串，產出 2,863 個詞句、1,443 個單字讀音，保留 138 條人工檢核的詞語／上下文校訂規則。註解也會被掃描；這不是不同頁面或題目數。

依據教育部《國語辭典簡編本》2014_20260929 官方資料比對詞語及人工檢查多音字上下文。只使用讀音事實，沒有匯入釋義。

- 官方資料：https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/dict_concised_download.html
- 一／不標示本調：https://dict.mini.moe.edu.tw/Home/Intro?Intro_id=5
- 精熟詞條：https://dict.revised.moe.edu.tw/dictView.jsp?ID=95680&la=0&powerMode=0

保留題目指定的注音（例如單字課程「卷」ㄐㄩㄢˋ）；一般介面統一使用同一字典。改正知識、長度／成長、重新／重點、跟著、返還、種樹、數學分子、解法、校準、伺服器、建築、供應等。角色「米白卷毛」改成「米白捲毛」。

比對剩餘 6 個差異已按上下文排除：也會計分不是會計；圖上相距不是上相；每次都會不是都會；紅蘿蔔與蓮蓬頭保留全詞有效輕聲；長尾巴描述長的尾巴，並非長出尾巴。不能把詞典子字串機械套進句子。

## 聲音

中英文混合提示分段選擇臺灣中文／英文語音；一年級英文保留中文任務說明；英文字母明示 letter。臺灣語音未就緒時等待 voiceschanged；不誤用粵語或其他中文語系。缺少必要語音時顯示訊息，Dialog 也呈現錯誤。保留錄音完成／取消及背景音樂暫停生命週期，沒有套用其他來源的裁切時間。

165 個目前使用中的 Higgsfield 錄音皆存在並通過 ffprobe 解碼；雜湊及長度見 recording-integrity.json。這是檔案驗證，不是聲學或逐首聽辨驗證。本次未能逐首聽辨錄音，亦不能保證所有裝置的合成引擎讀音；不宣稱所有實際聲音零錯誤。

## 驗證

- npm run build 通過（保留既有 bundle 大小提示）。
- 使用獨立 PostgreSQL 測試資料庫：30 個檔案、299 項測試全部通過，無跳過。
- 獨立唯讀複查最初提出 12 類漏網讀音與部分語音清單載入問題；修正後再查通過，22 項重點測試通過。
- 建置門檻：攔下新文字未覆蓋、缺字、注音格式／字數不符、已校訂詞句退回錯誤讀音、缺課程錄音。
- 故意加入未覆蓋字串、把知識改回錯音兩個負面驗證，皆被門檻拒絕。
- 實際二年級首頁 DOM 確認知識ㄓㄕˋ、種樹ㄓㄨㄥˋㄕㄨˋ、本調一；朗讀按鈕可操作，console 無錯誤。畫面見 grade-two-preview.png。

## 後續維護

新增文字後先依教育部資料檢查詞意與多音字，將必要規則加到 src/data/taiwan-zhuyin-overrides.json，再用 pypinyin 0.55.0 執行 scripts/build-zhuyin.py，檢查差異並跑 npm run check:pronunciation、npm test、npm run build。自動產生僅是草稿，不能將重新產生字典等同讀音校對通過。新增或替換錄音仍需逐首聽辨；檔案解碼不證明讀音正確。
